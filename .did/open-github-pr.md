# Feature: /pr Command to Open Related GitHub Pull Request

## Overview
Add a `/pr` slash command in `jules repl` (and `jules pr` CLI subcommand) to open or display the URL of the GitHub pull request generated by Jules for the current session.

## Detailed Requirements
- Read session details and artifacts from the Jules API to extract the associated GitHub PR URL (e.g., `https://github.com/owner/repo/pull/123`).
- If a source repository is defined and a PR has been created:
  - Output: `🌐 Opening pull request in browser: https://github.com/owner/repo/pull/123`
  - Automatically open the URL using `openUrlInBrowser(prUrl)`.
- If no source repository is linked or no PR has been generated yet for the session, display a clean notice:
  ```text
  No pull request URL found for this session.
  ```
- Add `/pr` to `jules repl` slash command `/help` documentation.
